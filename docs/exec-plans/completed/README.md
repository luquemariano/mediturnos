# Exec Plans completados

Un plan se mueve a `completed/` cuando cumple su criterio de finalización, ejecuta las validaciones acordadas y actualiza la documentación relevante.

Debe conservar el contexto y objetivo original, alcance, decisiones, arquitectura, permisos, tests, migraciones, validación final, riesgos residuales y documentación actualizada.

No se borra automáticamente después de completar la feature: conserva el contexto histórico y la evidencia del trabajo realizado.

La plantilla de referencia es [`../active/README.md`](../active/README.md).
