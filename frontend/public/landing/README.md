# Capturas reales de la landing

Capturas obtenidas de la aplicación local con el usuario profesional demo y exportadas en WebP:

- `dashboard.webp`: dashboard o agenda con datos demo.
- `dashboard-mobile.webp`: dashboard profesional real a 390 × 844 para el teléfono del hero.
- `pacientes.webp`: lista de pacientes con datos demo (no el estado vacío).
- `disponibilidad.webp`: configuración de disponibilidad.
- `prestaciones.webp`: gestión de prestaciones.
- `login.webp`: pantalla de acceso.
- `login-mobile.webp`: pantalla de acceso real capturada a 390 × 844.
- `login-security.webp`: recorte desktop del acceso para la sección de seguridad.

Las rutas están centralizadas en `src/landing/landingConfig.ts`. No se incluyen interfaces simuladas. Para renovarlas, usar una viewport de 1440 × 900, campos sensibles vacíos y datos exclusivamente demo.
